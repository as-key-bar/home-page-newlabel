# Gmail設定手順書

Nodemailerでメール送信機能を使用するために、以下の手順でGmailを設定してください。

## 1. Gmailアカウントの準備

お問い合わせメールの送信に使用するGmailアカウントを用意してください。

## 2. 2段階認証プロセスの有効化

1. [Googleアカウント設定](https://myaccount.google.com/)にアクセス
2. 「セキュリティ」→「2段階認証プロセス」をクリック
3. 指示に従って2段階認証を有効化

## 3. アプリパスワードの生成

1. Googleアカウント設定の「セキュリティ」ページ
2. 「アプリ パスワード」をクリック
3. 「アプリを選択」→「その他（カスタム名）」を選択
4. 「newlabel contact form」などの名前を入力
5. **生成された16桁のパスワードをコピー**（スペースは除く）

## 4. 環境変数の設定

`.env.local`ファイルを作成し、以下の内容を記述：

```env
# Gmail設定
ADMIN_EMAIL=あなたの受信用メールアドレス@gmail.com
GMAIL_USER=送信用gmailアカウント@gmail.com
GMAIL_APP_PASSWORD=16桁のアプリパスワード

# 送信者情報
FROM_NAME=".new label"
WEBSITE_URL=https://yourdomain.com
```

## 5. テスト

1. 開発サーバーを再起動：`npm run dev`
2. お問い合わせフォームからテスト送信
3. 以下を確認：
   - 管理者メール（ADMIN_EMAIL）にお問い合わせ内容が届く
   - 送信者に自動返信メールが届く

## ⚠️ 重要な注意事項

- `.env.local`は`.gitignore`に含まれているため、Gitにコミットされません
- アプリパスワードは絶対に公開しないでください
- 本番環境では環境変数を適切に設定してください

## トラブルシューティング

### 「Less secure app access」エラー
→ 2段階認証とアプリパスワードを使用すれば解決

### 「Invalid login」エラー  
→ GMAIL_USERとGMAIL_APP_PASSWORDを再確認

### メールが届かない
→ 迷惑メールフォルダも確認してください

## セキュリティのベストプラクティス

- 送信専用のGmailアカウントを作成することを推奨
- 定期的にアプリパスワードを更新
- 不要になったアプリパスワードは削除
